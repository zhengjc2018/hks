# a-stock-data 集成设计（2026-08-11）

## 目标

把 GitHub `simonlin1212/a-stock-data` 的高价值 A 股数据端点移植进 hks，
按 A → C → B 顺序落地：

- A：打板情绪、板块资金流、龙虎榜、两融、大宗、股东户数、分红、120日资金流、
  研报、互动易、人气榜。
- C：财联社电报、东财全球资讯。
- B：百度日 K 兜底、腾讯行情封装。

## 架构

- 新增 `astock_data.py`：独立数据模块，自带东财 `em_get()` 限流、会话复用、
  连接重试和个股聚合缓存；所有函数失败返回空结构。
- server 增加薄接口：`/api/market_sentiment`、`/api/board_fund_flow`、
  `/api/hot_rank`、`/api/stock_extra`、`/api/telegraph`。
- 首页增加「市场温度」四卡（打板情绪/板块资金/人气榜/快讯）；
  个股详情页增加「数据面」页签。
- `server._klines` 在通达信、新浪失败后尝试百度日 K；腾讯行情封装供估值兜底。

## 容错

- 东财接口统一限流，住宅 IP 被断连时返回空并展示“暂无数据”。
- `stock_extra` 按 `code + 日期` 缓存 6 小时。
- 所有新增端点不阻塞主流程。

## 验证

- 打板情绪、人气榜、快讯、个股数据面接口均返回真实数据。
- 板块资金流在当前网络被东财 push2 断连，空返回兜底。
